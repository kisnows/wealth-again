# PRD (`prd.md`) 功能符合度分析

本文件用于追踪项目功能与产品需求文档（PRD）的符合度。

## 3.1 总览 (Dashboard)

- [x] **核心指标展示**: 净资产、资产总额、负债总额、累计收入等。
- [x] **资产走势折线图**: 按月展示净资产趋势。
- [x] **资产分配饼图**: 按账户类别展示占比。
- [x] **账户概览表**: 列出重点账户。
- [x] **收入摘要卡片**: 展示收入与税费累计值。
- [x] **筛选能力**: 支持 `as-of` 日期与展示币种。
- [ ] **管理员用户切换**: 管理员可选择不同用户视角。

## 3.2 收入管理

- [x] **功能收敛**: 详细功能遵循 `income-spec.md`。
- [x] **统一入口**: 收入相关功能集中在 `/income` 路径。

## 3.3 账户模块

- [x] **功能收敛**: 详细功能遵循 `account-all.md`。
- [x] **统一入口**: 账户相关功能集中在 `/accounts` 路径。

## 3.4 税务与社保规则模块

- [x] **城市配置**: 维护社保、公积金规则。
- [x] **税务配置**: 维护年度税率表。
- [x] **专线扣除管理**: 用户可维护个人年度扣除额。
- [x] **回算工具**: 提供按年度重新计算收入记录的功能。

## 3.5 用户设置

- [x] **币种偏好**: 设置基准币种和展示币种。
- [x] **工作城市**: 设置工作城市与生效日期。
- [x] **年度专线扣除**: 输入与历史记录。

## 3.6 管理员工作台

- [x] **用户列表**: 查看和筛选用户。
- [x] **模拟登录**: 支持以用户身份登录。
- [x] **全局配置**: 编辑税率、城市规则。
- [x] **操作日志**: 记录管理员的敏感操作。
