# 收入与预测系统 PRD（v1.1 ｜补充社保/公积金/个税计算示例）

## 1. 收入类型与已确认规则

- **工资**

  - 变更记录：记录「变更日期、变更后工资」，**当月生效**
  - **每月 1 日发放**
  - 同月多次变更：以**最后一次**为准（建议）

- **奖金**

  - 一次性收入，配置「发放日期、金额」
  - 发放日所在**当月与工资合并发放**

- **长期现金**

  - 配置「总额、授予日期」
  - 自动拆分为 **16 次**（**按季度**发放），各期与当月工资合并发放
  - （默认等额 1/16；是否支持自定义权重可后续扩展）

- **社保 / 公积金**（“五险一金”，只计算**个人缴纳部分**）

  - **基数** = clamp(当月工资, 城市下限, 城市上限)
  - 各险种个人比例、固定额（如医保 3 元）及**上下限**均**因城市而异** → **配置化 + 按生效日期版本管理**

- **个税（累计预扣法）**

  - 月应纳税所得额（累计口径）= 累计(当月收入 – 社保 – 公积金 – 基本减除费用 – 专项附加扣除)
  - 基本减除费用建议按国家口径 **5000 元/月**（可配置；若你坚持不扣，可在配置中设为 0）
  - 当月应预扣个税 = 〔**累计应纳税额** × 税率 – 速算扣除数〕 – **累计已预扣税额**
  - 税率与速算扣除数按**年累计应纳税所得额**匹配（见下表）

## 2. 税率表（综合所得：年累计应纳税所得额）

> 用于累计预扣法；你的系统应**配置化**此表（不同年份可能有政策调整）

| 级数 | 年累计应纳税所得额（¥） | 税率 | 速算扣除数（¥） |
| ---: | ----------------------- | :--: | --------------: |
|    1 | 0 ～ 36,000             |  3%  |               0 |
|    2 | 36,000 ～ 144,000       | 10%  |           2,520 |
|    3 | 144,000 ～ 300,000      | 20%  |          16,920 |
|    4 | 300,000 ～ 420,000      | 25%  |          31,920 |
|    5 | 420,000 ～ 660,000      | 30%  |          52,920 |
|    6 | 660,000 ～ 960,000      | 35%  |          85,920 |
|    7 | > 960,000               | 45%  |         181,920 |

> 说明：**年累计应纳税所得额** = 自年初至当月累计〔（当月收入 – 社保 – 公积金 – 基本减除费用 – 专项附加扣除）〕。

## 3. 计算流程（研发可直接落代码）

**给定**：

- 当月工资（含当月变更后金额）、当月奖金、当月长期现金分期金额
- 城市配置：

  - 社保：各险种个人比例 & 固定额（例如医保个人 +3 元）、**基数上下限**
  - 公积金：个人比例、**基数上下限**

- 税务配置：基本减除费用（默认 5000/月）、专项附加扣除（若无填 0）、税率表

**步骤**（按月滚动，使用累计预扣法）：

1. 计算**社保、公积金基数**：

   ```
   social_base  = clamp(工资, 社保下限, 社保上限)
   housing_base = clamp(工资, 公积金下限, 公积金上限)
   ```

2. 计算**个人缴纳额**：

   ```
   pension_personal    = social_base * 养老个人比例
   medical_personal    = social_base * 医保个人比例 + 医保固定额(如 +3)
   unemployment_personal = social_base * 失业个人比例
   social_personal     = pension_personal + medical_personal + unemployment_personal
   housing_personal    = housing_base * 公积金个人比例
   ```

3. 计算**当月税前收入**：

   ```
   month_income = 工资 + 奖金 + 长期现金当期
   ```

4. 计算**当月应纳税所得额（当期项）**：

   ```
   taxable_current = month_income - social_personal - housing_personal
                     - 基本减除费用 - 专项附加扣除
   ```

5. 累加到**累计应纳税所得额**：

   ```
   taxable_cum = 上月 taxable_cum + taxable_current
   ```

6. 用表匹配**税率/速算扣除数**并计算**累计应纳税额**：

   ```
   tax_cum = taxable_cum * 税率 - 速算扣除数
   ```

7. 计算**当月应预扣个税**与**实发**：

   ```
   tax_due_month = tax_cum - 上月已预扣个税累计
   net_pay       = month_income - social_personal - housing_personal - tax_due_month
   ```

## 4. 示例参数（**示例配置，仅用于演示**）

- 员工工资：**自 2025-01 起为 ¥20,000**（当月生效）
- 奖金：**2025-03 发放 ¥30,000**
- 长期现金（LTC）：**总额 ¥160,000，授予 2025-01** → **季度发放**，每期 **¥10,000**（2025-01/04/07/10/…）
- 城市（示例）基数上下限：

  - **社保上下限：¥5,000 ～ ¥25,000**
  - **公积金上下限：¥5,000 ～ ¥25,000**

- 个人比例（示例）：

  - 养老 **8%**；医保 **2%** + 固定 **¥3**；失业 **0.5%**
  - 公积金 **12%**

- 税务配置（示例）：

  - 基本减除费用 **¥5,000/月**
  - 专项附加扣除 **¥0**（示例）

> 注：真实城市比例与上下限以当地最新政策为准；系统采用**配置化**，此处仅为演算示例。

## 5. 月度计算示例（2025 年 1–3 月）

### 统一中间量（因工资 20,000 落在上下限内，基数即 20,000）

- **社保（个人）**

  - 养老：20,000 × 8% = **1,600**
  - 医保：20,000 × 2% + 3 = **403**
  - 失业：20,000 × 0.5% = **100**
  - 合计：**2,103**

- **公积金（个人）**：20,000 × 12% = **2,400**
- **五险一金（个人合计）**：**4,503**

---

### 1 月

- 月收入：工资 20,000 + LTC 10,000 = **30,000**
- 当期应纳税所得额（当期项）：
  30,000 – 4,503 – 5,000 = **20,497**
- 累计应纳税所得额：**20,497**（首月）
- 对应税率：**3%**（≤ 36,000），速算扣除数 **0**
- 累计应纳税额：20,497 × 3% = **614.91**
- 当月应预扣个税：**614.91**（因上月累计为 0）
- **1 月实发**：30,000 – 4,503 – 614.91 = **¥24,882.09**

---

### 2 月

- 月收入：工资 20,000 = **20,000**
- 当期应纳税所得额（当期项）：
  20,000 – 4,503 – 5,000 = **10,497**
- 累计应纳税所得额：20,497 + 10,497 = **30,994**
- 税率：**3%**；速算扣除数 **0**
- 累计应纳税额：30,994 × 3% = **929.82**
- 当月应预扣个税：929.82 – 614.91 = **314.91**
- **2 月实发**：20,000 – 4,503 – 314.91 = **¥15,182.09**

---

### 3 月

- 月收入：工资 20,000 + **奖金 30,000** + LTC 10,000 = **60,000**
- 当期应纳税所得额（当期项）：
  60,000 – 4,503 – 5,000 = **50,497**
- 累计应纳税所得额：30,994 + 50,497 = **81,491**
- 税率：**10%**（36,000 ～ 144,000），速算扣除数 **2,520**
- 累计应纳税额：81,491 × 10% – 2,520 = **5,629.10**
- 当月应预扣个税：5,629.10 – (614.91 + 314.91) = **4,699.28**
- **3 月实发**：60,000 – 4,503 – 4,699.28 = **¥50,797.72**

---

### 1–3 月汇总（示例）

| 月份 | 税前收入 | 社保个人 | 公积金个人 |     当月个税 |      税后实发 |
| :--: | -------: | -------: | ---------: | -----------: | ------------: |
| 1 月 |   30,000 |    2,103 |      2,400 |   **614.91** | **24,882.09** |
| 2 月 |   20,000 |    2,103 |      2,400 |   **314.91** | **15,182.09** |
| 3 月 |   60,000 |    2,103 |      2,400 | **4,699.28** | **50,797.72** |

> 校验：3 月累计应纳税额 5,629.10 = 614.91 + 314.91 + 4,699.28 ✅

## 6. 落地建议（关键字段与配置）

- **城市口径配置**

  - `social_base_lower/upper`、`housing_base_lower/upper`
  - `pension_rate_personal`、`medical_rate_personal`、`medical_fixed_personal`、`unemployment_rate_personal`
  - `housing_rate_personal`
  - **生效日期**（年度切换/中途调整）

- **税务配置**

  - `basic_deduction_monthly`（默认 5000，可设为 0 以匹配你的简化口径）
  - `special_additional_deduction_monthly`（默认 0，可由用户维护）
  - `tax_brackets[]`（阈值、税率、速算扣除数、版本）

- **对账字段**

  - `taxable_current`、`taxable_cum`、`tax_cum`、`tax_due_month`、`tax_paid_cum`
  - 保证任何月份可**重算 & 校验**

## 7. 备注

- 上述示例中的**比例、上下限仅为演示**；实际以当地当年政策为准。
- 若你坚持采用**不扣 5000 基本减除费用**的简化口径，只需在配置中把 `basic_deduction_monthly = 0`，公式与步骤保持一致，示例数字会随之变化。
