# 文档总览（Single Source of Truth）

> 本索引帮助你定位唯一可信的产品、技术与实施文档。新增或调整信息时，请优先更新对应文档，并在此处同步链接，确保团队始终对齐同一事实来源。

## 产品需求（PRD）
- `doc/prd.md`：平台总体定位、角色权限、核心功能与业务规则。
- `doc/prd-income.md`：收入域的详细需求、计算规则、验收示例与回算要求。

## 技术设计
- `doc/tech.md`：整体系统架构、服务端领域服务、数据模型概览、测试策略与运维流程。
- `doc/frontend-constraints.md`：前端实现规范（目录结构、SWR/状态管理、表单与组件规范）。涉及页面交互请与 `doc/ui-routing.md` 联动维护。
- `doc/data.md`：Prisma schema 结构、杭州 2023-2025 规则样例与数据来源说明。

## UI / 交互设计
- `doc/ui-routing.md`：App Router 路由图、页面模块与交互说明，是前端与产品对齐页面行为的权威来源。

## 规划与落地
- `doc/plans/prd-income-implementation-plan.md`：收入域当前改造计划、差距分析与验收标准。

## 文档维护指引
- 更新业务逻辑时先确认对应 PRD/Tech/UI 文档是否需要同步调整。
- 若出现跨域变更（例如收入计算影响前端展示），请同时更新涉及的多份文档并在提交说明中指出。
- 避免在多份文档里重复描述相同细节；必要时插入链接指向单一来源。
