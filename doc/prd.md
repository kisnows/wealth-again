# 📘 个人财富与收入管理平台 PRD（交付版）

## 1. 产品定位与目标
- **统一视角**：提供资产、负债、收入、税务的一体化视图，回答“当前净资产、负债、收入与税赋状况如何”。
- **多币种个人财务管家**：支持多币种账户与实时折算，帮助用户理解资产构成与走势。
- **收入与税务精算**：覆盖工资、奖金、长期激励、股权激励等收入形态，结合城市社保、公积金与年度个税规则进行累计预扣计算。
- **可执行的预测与调整**：生成月度收入预测并允许人工调整，帮助用户对齐真实收入。
- **低门槛管理**：管理员可协助维护配置并模拟登录排查问题；普通用户关注自身资产与收入。

## 2. 角色与权限
- **普通用户**
  - 查看与维护自己的账户、交易、估值、收入记录、规则偏好与报表。
  - 管理个人年度“专线扣除”（专项附加扣除）值、基准币种、工作城市。
  - 发起年度收入回算、导出个人数据。
- **管理员**
  - 拥有普通用户所有能力。
  - 查看所有账户、收入与规则配置列表，支持按用户筛选。
  - 以管理员身份模拟登录任意用户，排查或代为调整数据，操作需记录来源管理员。
  - 维护全局字典（税率表、社保与公积金规则等）。
- **审计角色不在范围内**，但系统需保留关键操作日志供运维追踪。

## 3. 功能模块拆分

### 3.1 总览（Dashboard）
- 默认展示“本年度截至当前”的净资产、资产总额、负债总额、累计收入、累计税费、累计社保、公积金、本月收入、当前年度有效税率。
- 图表组件
  - **资产走势折线图**：按月展示净资产趋势，支持切换时间范围（1 年、3 年、全部）。
  - **资产分配饼图**：展示资产按账户类别（储蓄/投资/借贷/其他）的占比。
  - **账户概览表**：列出重点账户余额、估值、收益率。
  - **收入摘要卡片**：展示税前收入、税后收入、社保、公积金、税额等累计值。
- 筛选能力：
  - `as-of` 日期与展示币种（默认使用用户设置）。
  - 管理员可在头部选择用户或从 impersonate 模式进入。
- 数据来源：
  - 报表服务聚合账户余额、估值、汇率与月度收入记录。
  - 汇率折算默认采用最近一期快照；缺失时提示补录。

### 3.2 收入管理
- 收入模块的详细产品需求、业务流程、计算规则、技术规格与验收标准，已统一收敛至《[./income-spec.md](./income-spec.md)》。
- 本 PRD 仅保留对模块的整体定位，所有细节均以该文档为准。

### 3.3 账户模块
- 账户模块的详细产品描述、规则、数据模型与验收标准已沉淀至《[doc/account-all.md](./account-all.md)》。
- 本 PRD 仅保留模块定位，其余内容以该文档为准，更新需保持同步。

### 3.4 税务与社保规则模块
- **城市配置**：维护 `effectiveFrom`、`effectiveTo`、社保上下限、各险种个人比例、固定额、公积金上下限与比例；禁止区间重叠。
- **税务配置**：维护年度税率表（阈值、税率、速算扣除数）、基本减除费用、专项附加扣除年度冲减策略。
- **专线扣除管理**：
  - 用户端维护个人年度扣除额；管理员可查看所有用户录入情况。
  - 支持年度复制与批量导入。
- **回算工具**：提供 `/income/recalc` 接口和前端入口，按年度重新计算收入记录。

### 3.5 用户设置
- 基准币种、展示币种偏好。
- 工作城市与生效日期（影响社保、公积金规则选择）。
- 年度专线扣除输入与历史记录。
- 用户级别的通知与提醒设置（即将到期的估值、规则缺失等）。

### 3.6 管理员工作台
- 用户列表：查看基础信息、最近登录、账户/收入概览；支持搜索、筛选。
- 模拟登录：点击进入用户视角，顶部展示“管理员模式”。
- 全局配置：编辑税率表、城市规则、系统参数（基准币种等）。
- 操作日志：记录管理员模拟登录、全局配置变更、删除账户/收入记录等敏感操作。

## 4. 数据与实体概览
- **账户与交易**：User ↔ Account ↔ TransactionEntry/TransactionLine，估值快照表，汇率表（FxRate）。
- **收入与激励**：IncomeChange、BonusPlan、LongTermCashPlan、LongTermCashPayout、EquityGrant、EquityVest、IncomeRecord。
- **规则配置**：CitySocialSecurityRule、CityHousingFundRule、TaxConfig、TaxBracket、UserAnnualDeduction（专线扣除）。
- **系统支撑**：UserPrefs（币种、城市）、AuditLog、ImpersonationSession、IdempotencyKey。

## 5. 报表与导出
- **资产报表**：
  - 账户汇总（资产/负债）、净资产趋势、资产分布。
  - 可按时间范围、币种过滤，支持导出当前视图。
- **收入报表**（入口统一在 `/income`，`/reports/income` 仅做跳转）：
  - 月度明细表：税前收入、奖金、长期激励、股权、社保、公积金、个税、税后收入、人工调整标记。
  - 预测视图：展示未来 12 个月预测值，并标注人工覆盖字段。
- **税务报表**：年度累计应纳税额、已缴税、待缴税、有效税率、专线扣除使用情况。
- **管理员导出**：可导出全体用户收入/账户统计表，用于支持运营分析。

## 6. 业务规则与校验
- 规则区间不得重叠，系统在保存时进行校验，提示冲突配置。
- 账户币种创建后不可变更；跨币种交易必须关联汇率快照。
- 收入人工调整需记录操作者与说明；管理员模拟登录时记录真实操作者为管理员。
- 回算操作需提示“将覆盖 X 月至 Y 月的计算结果”，执行后重新写入 IncomeRecord。
- 以年度为范围的专线扣除仅对对应年度生效，不影响跨年度计算。

## 7. 非功能性要求
- **准确性**：所有财务计算支持追溯；保持与配置版本一致，可重算历史月份。
- **性能**：支撑 10 年以上月度数据（约 120+ 条），Dashboard 加载时间 < 2s（缓存 + 按需加载）。
- **安全性**：管理员模拟登录需双重确认；敏感操作写入 AuditLog（含管理员 ID、用户 ID、时间、操作内容）。
- **可拓展性**：配置均以生效时间管理，支持政策变更；收入类型可扩展。
- **可用性**：前端使用 shadcn/ui + Tailwind，支持浅/深色模式与无障碍访问。

## 8. 里程碑与交付检查
1. **MVP**：账户管理、基础收入录入与计算、Dashboard 核心指标。
2. **阶段一**：完成全部收入类型、人工调整、年度回算、城市/税务配置。
3. **阶段二**：管理员模拟登录、操作日志、预测导出。
4. **验收**：
   - 输入 doc/prd-income.md 示例数据，核对 1–3 月个税、社保、公积金与文档一致。
   - 人工调整后预测值正确覆盖计算值。
   - 管理员模拟登录状态下操作记录正确。
   - Dashboard 与报表数据与账户/收入记录对齐。
